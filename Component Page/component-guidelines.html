Component Guidelines - Buttons

In Prompt Llama, buttons are typically reserved for forms at the bottom of the page, like the AI artists submission form.
Buttons sometimes use images rather than text to convey their meaning. This can be observed in the search button next to the search bar.


Buttons have four states:

The button is ready to be clicked. Has a Bold and eye-catching appearance. The color of the text changes depending on the type of button to always have good contrast and make the text easy to read.

The button is being hovered over by the user. Colors of button and label change drastically, making user feedback clear and eye-catching.

The button has been clicked, as indicated by a white background and the highlighted text color.

The button cannot be clicked. Buttons have a uniform gray color that makes them less prominent. Label text is also closer in shade of gray to background, making it stand out less.


Buttons have three types:

This is an effective type for the main buttons on the page. In the case of Prompt Llama, this is used for the search bar button.

This type can be used for any attention-grabbing elements you want on the page. Prompt Llama doesn't utilize this yet, but having the style here allows for flexibility in design ideas down the road.

Paired with the dark section at the bottom of pages, this button works well as a compliment for darker color schemes. This button is not currently used in Prompt Llama.

*All buttons share the same disabled appearance.

Padding

All Buttons conform dynamically to their text by default using a padding of 16px, or var(--spacing-medium), around their text. This is done to center their text and help maintain a consistent spacial appearance. However, this can be adjusted if buttons look strange when varying lengths are next to one another.
